# Do I have to include a date when creating a Markdown file in the `_posts` folder?

In Jekyll's default behavior, Markdown file names in the `_posts` folder must include a date.  
The file name format should be `YYYY-MM-DD-title.md` for Jekyll to recognize it as a blog post.  
However, if you want to add a Markdown file without a date, there are alternative methods.

---

## 1. Basic rule: File names must include a date (YYYY-MM-DD-title.md)

- Including a date in the file name allows Jekyll to automatically recognize it as a `post` and sort it by date.
- Useful for automatically generating `latest posts` or `archive` pages in the blog.
- Jekyll automatically recognizes the date in the file name as the post's publication date (`date:`).
- If the file name and `date:` value match, the date is set automatically.
